# PizzeriaBellaNapoli
📁 Organizzazione dei file

index.html — Home page del sito. Non modificarla senza autorizzazione.

style.css — Stile grafico comune a tutte le pagine. Le modifiche devono essere concordate con il responsabile.

pizze.html — Pagina dedicata alle pizze.

bevande.html — Pagina dedicata alle bevande.

dolci.html — Pagina dedicata ai dolci.

👨‍💻 Cosa deve fare ogni componente del gruppo

Scegliere la propria sezione: pizze, bevande oppure dolci.

Creare un branch personale partendo dal branch main, senza lavorare direttamente su main.

Modificare esclusivamente il file assegnato, inserendo i contenuti della propria sezione.

Inserire per ogni prodotto:

Nome del prodotto.

Descrizione o ingredienti.

Prezzo.

Eventuale immagine, se disponibile.

Mantenere la struttura HTML corretta e utilizzare le classi CSS concordate per garantire uno stile uniforme.

Verificare che la pagina sia leggibile, ordinata e funzionante.

Fare commit delle modifiche sul proprio branch e caricarlo su GitHub.

Aprire una Pull Request verso main, descrivendo le modifiche effettuate.

Attendere il controllo e l'approvazione del responsabile prima del merge.
